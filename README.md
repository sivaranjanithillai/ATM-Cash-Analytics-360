# 🏧 ATM Cash Analytics 360

## 📊 Project Overview

ATM Cash Analytics 360 is a Power BI dashboard designed to analyze ATM transactions, cash availability, ATM performance, operational failures, and location-wise transaction insights.

## 🎯 Project Objectives

- Analyze ATM transaction activity
- Monitor cash withdrawal and deposit trends
- Identify failed transactions and failure reasons
- Analyze ATM performance
- Monitor low-cash situations
- Compare city-wise ATM activity
- Identify operational insights

## 🛠️ Tools & Technologies

- Power BI
- Microsoft Excel
- DAX
- Data Analytics
- Data Visualization

## 📄 Dashboard Pages

1. 🏠 Home
2. 📊 Executive Overview
3. ⚙️ ATM Operations
4. 📈 ATM Performance
5. 💰 Cash Management
6. 📍 Location Intelligence

## 📈 Key Analysis

- Total Transactions
- Total Cash Withdrawn
- Transaction Success Rate
- Failed Transactions
- Low Cash Transactions
- ATM-wise Performance
- City-wise Transaction Analysis
- Cash Replenishment Analysis
